# Typst for Note-Takers

Typst is a markup-based typesetting system. This note shows what obs2pdf
does with ordinary [[Obsidian]] notes: ==highlights==, wiki links, lists,
tables, code and quotes.

## Why Typst

- Fast incremental compilation
- Readable markup, real scripting
- Good error messages

> Typesetting should be as easy as writing Markdown, and as powerful as LaTeX.

### Compared to LaTeX

| Aspect  | Typst | LaTeX |
| ------- | ----- | ----- |
| Speed   | fast  | slow  |
| Syntax  | light | heavy |

## Getting started

1. Install Typst
2. Write a `.typ` file
3. Run `typst compile`
